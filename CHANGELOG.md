## 2.2.0
- Breaking: iOS support is now Swift Package Manager only. CocoaPods support
  and the Objective-C iOS implementation have been removed. Consumers must use
  a Flutter version with SwiftPM plugin support.
- Migrated Android plugin builds to Flutter's built-in Kotlin support.
- Updated minimum Flutter SDK to 3.44 and Dart SDK to 3.12.0.
- Converted the iOS plugin implementation to an all-Swift package under
  `ios/threadable_better_player`.
